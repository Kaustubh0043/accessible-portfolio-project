# Week 3: JavaScript Logic & State Management

**Status:** Task outline — add your completed project files here.

## Task

Build an interactive client-side To-Do List application to practice DOM manipulation, event handling, and browser storage.

## Requirements

- Support creating, reading, updating, and deleting tasks.
- Save tasks in `localStorage` so they remain after a browser reload.
- Filter the list by All, Active, and Completed.
- Create and update page elements dynamically and use delegated event handling.

## Suggested files

Add the app's `index.html`, stylesheet, JavaScript, and a short README describing the features and how to run it.
