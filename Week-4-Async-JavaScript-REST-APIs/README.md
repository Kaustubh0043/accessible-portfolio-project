# Week 4: Asynchronous JavaScript & RESTful APIs

**Status:** Task outline — add your completed project files here.

## Task

Build a real-time Weather Dashboard that fetches and processes JSON data from a public REST API using asynchronous JavaScript.

## Requirements visible in the task brief

- Fetch real-time data with the modern Fetch API and `async`/`await`.
- Handle failed network requests and other errors clearly.
- Parse nested JSON data and render the results dynamically.
- Let users search for weather information by city.

## Suggested files

Add the app's `index.html`, stylesheet, JavaScript, and a README explaining the API used, setup steps, and how to run it. Check the API provider's terms and keep any private API keys out of public files.
